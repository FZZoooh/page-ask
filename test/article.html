浏览器扩展侧栏开发入门

作者：张三 · 2026 年 11 月 3 日 · 预计阅读 6 分钟

Manifest V3 引入了 chrome.sidePanel 接口，让扩展可以在浏览器右侧常驻一个面板。 与弹出式 popup 不同，侧栏不会在失去焦点时关闭，因此更适合承载多轮对话这类长时间交互。

三个必备步骤

  1. 在 manifest 中声明 "side_panel": { "default_path": "sidepanel.html" }
  2. 申请 sidePanel 权限
  3. 调用 sidePanel.setPanelBehavior({ openPanelOnActionClick: true })，让点击图标就能打开

读取当前页面的正文

读取页面依赖 scripting 权限。只有在用户点击扩展图标时，浏览器才会把那一个标签页的 访问权临时授予扩展，这就是 activeTab 的设计意图——最小权限。 

const [tab] = await browser.tabs.query({ active: true, currentWindow: true });
const results = await browser.scripting.executeScript({
  target: { tabId: tab.id },
  func: () => document.documentElement.outerHTML,
});

常见问题

现象原因
侧栏打不开缺少 sidePanel 权限，或 manifest_version 不是 3
读不到页面页面是 edge:// 内部页面，或没有 activeTab 授权
切回标签页侧栏消失Edge 的已知缺陷，需要再次点击图标

最后一点值得强调：正文提取的质量直接决定问答质量。把整个 DOM 丢给模型既浪费 token， 又会引入导航栏、广告、评论区这些噪音，所以必须先用 Readability 一类的算法做一次清洗。

  • 优点是实现简单，两个库都在几十 KB 量级；
  • 缺点是对 SPA 站点、Shadow DOM 支持有限；
  • 建议永远保留一条「纯文本回退」路径。
